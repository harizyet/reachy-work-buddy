# Robot-host deployment

Daemon installer, systemd units (the daemon, and `reachy-embodiment.service`
which starts the container only after the daemon's camera socket exists) and
robot environment template. The confirmed
host is the original Jetson Nano; physical acceptance remains incomplete.
