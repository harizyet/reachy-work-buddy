# Phase 44F: implementation slices (preparation only; not authorized, not started), 2026-10-11

Source design: [Phase 44 section 3.1 and 3.1a](phase-44.md#31-44f-conversational-memory-capture-roadmap-2026-10-08-plan-only) (candidates are not memory; selection mechanisms order and suggest, never accept). This page cuts it into slices that can be built, tested and reviewed one at a time. **No code and no migration exists for any of them.** "Curiosity" is not defined anywhere in the repository; the definition in slice 8 is my proposal and needs the owner's confirmation.

## Rules that apply to every slice

Casual conversation never becomes authoritative memory without the owner's explicit accept. Local-only. Privacy mode, shared and non-private channels, sensitive turns, assistant text and retrieved or attached content produce no candidates. Everything is behind its own flag, off by default, with a per-slice owner approval. Receipts for every accepted write. No change to consent, trust or the text-only destructive-confirmation rules. Tests on disposable infrastructure, including live-route injection cases (a planted instruction cannot create a candidate, change its priority or accept it).

## Suggested order and review points

0, 1, 2, 3 form the first usable milestone (a reviewed, owner-controlled candidate queue from deterministic rules); 4 is the second; 5 to 7 and 9 are selection and presentation upgrades judged on owner-reviewed data; 8 is last and optional. Each slice ends with a dated verification record and an owner decision before the next begins.
