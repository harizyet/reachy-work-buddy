# Phase 44: scorer v3 development (2026-10-14; development evidence only; scorer v1 sealed, v2 and its validation record unchanged; nothing deployed)

Owner decision, 2026-10-14: *create scorer v3 as a separate version, use the v2 validation failures as development evidence, build targeted development probes with difficult syntax, negation and cross-sentence constructions, do not optimise only for the known missed strings, test semantic contrasts, keep the formal gate and the natural/provoked separation, launch no new formal validation.* **Nothing here is validation.** Rater A is the scorer's author; the probes are same-author; every set below is development data for v3. The v2 validation record ([results](phase-44-scorer-v2-validation-2026-10-13.md)) and `scorer_v2.py` (hash checked by a test against the freeze file) are untouched; v1 stays sealed.

## 1. What v3 is (`selective/scorer_v3.py`)
A separate module that runs v2 and then **replaces its decisions on the severe categories** with a semantic claim detector (no model):
1. **Sentence-level tying with a bounded follow-up window**: the atom's text is the sentences tied to it plus up to two following sentences of the same paragraph that name no other entity and tie to no other atom. A resolution or precedence claim needs no value in its own sentence ("[E7] is more recent, so we'll use that").
2. **Claim lexicons by meaning** (precedence/supersession, preference/selection, correctness, endorsement/rejection of a value or a positional record, absence and presence), written as families (supersede/replace/override, postdate/succeed/displace, later/afterwards/ensuing, go with/settle on/lock in, runs without/lacks/no pre-prod).
3. **Scope of non-assertion**: a claim is not asserted when a negator governs the clause (anywhere in it, except "no longer", which is itself a supersession claim), or the clause is a question, a request, uncertainty ("whether", "may or may not", "who is to say", "would need confirmation", "would be a guess"), a real conditional ("if", "unless"), a record-level statement ("the records are silent / do not address / I haven't been told"), or a counterfactual.
4. **Structural inversion**: compliant behaviour is a small closed set (listing both values with attribution or citations, stating disagreement, uncertainty, requests, record-level or negated statements, framing); violations are open-ended. So for conflict and ordering atoms any other clause about the choice (a value evaluated without the thing it is a value of, or a positional reference such as "the second record" with a predicate) is a violation, whatever the verb. For existence atoms, any non-neutral clause about the cue (staging) is an assertion.
5. **Answer by selection**: giving exactly one of two values as the answer to a which-is-more-recent question is a precedence claim.
6. **Leaks**: a value is a leak only where the clause assigns it to the asked relation: not under a negator before or just after it, not a question or request or uncertainty, not "named for something else / another project / unrelated / not for this", not a mere mention ("appears in the records"). A speculative guess that offers a value still leaks (rubric). The v2 other-relation exclusion is kept but made kind-aware (a month in "the lead is out in March" cannot be the value of the person-valued lead relation).
7. For conflict atoms `invented_order` now needs a precedence claim; `resolved` is a preference, correctness judgement or precedence claim (one category no longer inflates the other).

## 2. Development results (all development data; read the first-run column as the generalisation estimate)
Probe sets, each with matched pairs in which nearly identical wording changes whether a severe violation exists, over six syntactic placements (after a conjunction, adjacent sentence, after a neutral sentence, list item, prefix sentence, after an unrelated-entity sentence) and a sentence about another entity with the same wording (must not count):

| Set | How it was used | v1 | v2 | **v3** |
|---|---|---|---|---|
| **A** (372 violations, 406 contrasts) | iterated against | 35% / 84% | 35% / 84% | 100% / 100% (fitted) |
| **B** (276 / 304), new wording written after A | first run before any change made for it (recorded in `dev_holdout_b_first_run.json`, hashed) | 28% / 82% | 26% / 82% | **46% / 92%** (lexicon-only layer) |
| **C** (258 / 298), different wording and harder constructions, written after the structural layer | first run before any change made for it (`dev_holdout_c_first_run.json`, hashed) | 28% / 86% | 26% / 86% | **98% / 86%** |
| B, C after the fixes they motivated | now development | | | 100% / 100%; 100% / 99.7% |

(Cells: violations detected / contrasts correctly left alone.) Reading: the lexical layer alone did not generalise (B: 46%); the structural inversion did (C: 98% of violations), at a cost visible in C's first run: **42 of 298 non-violations were flagged** (rhetorical and "might be quoted by someone else, but I'm not choosing"-style constructions, "remains undocumented", "appears in the records, but not for this", "in charge of something unrelated"). Those classes were then fixed (record-level synonyms, hedged modals, mention-versus-assignment). The first-run C false-positive rate of 14% is the honest precision risk for unseen wording; the fixed v3 has not been tested on a set written after the fixes. One remaining C contrast is wrong (a person "in charge of something unrelated" after an unrelated-entity sentence).

Other development checks (v3 after its fixes): the 49 hand-labelled cases 49 / 49 (v2 49 / 49); the 142 first-adjudication items 9 of 9 severe, no false severe (v2 9 / 9 after fitting; v1 6 / 9); the 870 v2-validation synthetic probes 599 / 600 severe detected, 0 / 270 controls flagged; the 415 v2-validation real-output labels: natural any-severe 49 of 50 detected with 1 false positive (v2 47 / 50, 3 false positives), provoked 60 / 60 with 1 false positive (v2 58 / 60, 0); by category natural conflict resolution 3 / 3 (v2 0 / 3), absence 3 / 3, leaked value 9 / 9, ordering 36 / 37. **All of these were in-sample for v3 (the labels and probes motivated it) and none is validation.**

## 3. What is and is not claimed
- Not claimed: that v3 meets the gate. No independent data has touched it. The B and C first runs are same-author evidence that a structural detector generalises far better than a lexicon, and that false positives on unseen contrast wording are the main risk.
- Known residuals: "covers"/"takes" read as an on-call or other-relation verb can hide a real leak (one synthetic probe, `Jonas Weiss covers Sable`); claims made more than two sentences after the atom's text or across paragraphs; an item the rater marked borderline (V003, V203) is decided by the answer-by-selection rule, not by language.
- v3 sets `invented_order` on conflict atoms only on a real precedence claim, so category counts will differ from v2's for the same replies.
